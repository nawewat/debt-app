เว็บแอปบันทึกลูกหนี้และคำนวณดอกเบี้ยรายงวด ใช้ได้ทั้งมือถือและคอม ฟรีทั้งหมด (GitHub Pages + Firebase Spark)

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (มี Firebase config อยู่ในไฟล์) |
| `manifest.webmanifest` | ตั้งค่าแอปตอนเพิ่มลงหน้าจอโทรศัพท์ |
| `icon-192.png`, `icon-512.png` | ไอคอนแอป |
| `firestore.rules` | กฎความปลอดภัย Firestore (สำเนาไว้อ้างอิง) |
| `README.md` | ไฟล์นี้ |

## โครงสร้างข้อมูลใน Firestore

```
users/{uid}/
  meta/key        กุญแจเข้ารหัส (ล็อกด้วยรหัสผ่านผู้ใช้)
  meta/profile    โปรไฟล์ (เข้ารหัส)
  debtors/{id}    ลูกหนี้ (เข้ารหัส)
  txs/{id}        รายการยืม/คืน (เข้ารหัส)
  slips/{id}      รูปสลิป (เข้ารหัส)
  files/{id}      รูปบัตรประชาชน (เข้ารหัส)
```

## วิธีอัปเดตแอป

1. แก้หรือรับไฟล์ `index.html` ตัวใหม่
2. ใน repo กด **Add file › Upload files** → ลากไฟล์มาวาง (ทับไฟล์เดิมอัตโนมัติ)
3. กด **Commit changes**
4. รอ 1–2 นาที ดูที่แท็บ **Actions** ว่าขึ้น ✅
5. บนมือถือ: ปิดแอปแล้วเปิดใหม่ (ถ้ายังเห็นของเก่า ให้เปิดใน Safari แล้วรีเฟรช)

ข้อมูลผู้ใช้อยู่ใน Firebase จึงไม่หายเวลาอัปเดตไฟล์

## ใช้งานบนโทรศัพท์

- **iPhone (Safari):** ปุ่มแชร์ ⬆️ › **Add to Home Screen**
- **Android (Chrome):** เมนู ⋮ › **Install app / Add to Home screen**

## การตั้งค่า Firebase (ทำครั้งเดียว — ทำแล้ว)

1. Authentication › Sign-in method › เปิด **Email/Password**
2. Firestore Database › สร้างที่ `asia-southeast1` › แท็บ Rules วางข้อความจาก `firestore.rules` › Publish
3. Authentication › Settings › Authorized domains › เพิ่ม `nawewat.github.io`

## ข้อควรรู้

- 🔑 **ลืมรหัสผ่าน = กู้ข้อมูลไม่ได้** เพราะข้อมูลเข้ารหัสด้วยรหัสผ่านของผู้ใช้เอง และไม่มีใครถือกุญแจสำรอง
- 👀 ผู้ดูแลระบบเห็นได้แค่ username, วันที่สมัคร/ล็อกอิน และจำนวนรายการ
- 📦 โควตาฟรี Firebase: พื้นที่ 1 GB, อ่าน 50,000 / เขียน 20,000 ครั้งต่อวัน — เพียงพอสำหรับใช้งานส่วนตัว
- 📶 เปิดแอปแล้วใช้ต่อได้ตอนเน็ตหลุดชั่วคราว ข้อมูลซิงก์เมื่อเน็ตกลับมา
